Supermart Grocery Sales Analysis

Project Overview

An Excel-based Business Analysis project using Supermart Grocery Sales data.

Tools Used

- Microsoft Excel
- Excel Formulas
- Pivot Tables
- Charts and Data Analysis

Analysis Areas

- Sales and Profit Analysis
- Category and Subcategory Analysis
- Region and City Analysis
- Customer Analysis
- Discount Analysis
- Business Insights

Objective

To analyze business performance and identify opportunities to improve sales and profitability.
